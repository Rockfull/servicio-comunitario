Diseño del certificado

Usa el diseño institucional predeterminado o sube tu modelo genérico en PDF: los datos de cada estudiante se sustituyen automáticamente.

Modelo Genérico de Certificado PDF o Imagen

Sube el PDF base o genérico de tu institución. Sobre este modelo se estamparán dinámicamente las variables de cada persona.

Variables que se reemplazan automáticamente:
  • {{nombre}} Nombre y Apellido del participante
  • {{curso}} De qué fue el certificado (actividad, taller, área)
  • {{fecha}} Mes y Año de culminación
  • {{cedula}} Cédula de Identidad (C.I.)

Si tu PDF ya tiene estos textos escritos, el sistema detecta sus coordenadas de forma automática. Si no, puedes arrastrar cada campo a su posición.
